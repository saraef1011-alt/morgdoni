# مرغ‌دونی آنلاین — Node.js

این شاخه یک پروژهٔ واحد برای اجرای رابط بازی موجود با سرور Node.js است. فایل‌های اصلی بازی و کارت‌ها حفظ شده‌اند؛ سرور HTTP فایل‌های پروژه را سرو می‌کند و WebSocket پیام‌های آنلاین را منتقل می‌کند.

## اجرای محلی
نیازمندی: Node.js نسخهٔ 20 یا بالاتر.

```bash
npm install
npm test
npm start
``

سپس `http://localhost:3000` را باز کن. مسیر `/healthz` باید پاسخ `ok` بدهد.

## استقرار روی Render
فایل `render.yaml` در این شاخه تنظیمات سرویس را آماده می‌کند. در Render گزینهٔ **New Blueprint** را انتخاب و همین مخزن و شاخهٔ `nodejs` را وصل کن. برنامه از متغیر محیطی `PORT` استفاده می‌کند و مسیر سلامت آن `/healthz` است.

**ذخیره‌سازی:** وضعیت و حساب‌ها در پوشهٔ `.data` نوشته می‌شوند. برای حفظ داده‌ها بعد از راه‌اندازی مجدد، دیسک پایدار باید در سرویس میزبان فعال و به `/app/.data` متصل شود؛ در محیط فاقد دیسک پایدار ممکن است اطلاعات پس از استقرار مجدد پاک شوند. یک نمونهٔ سرور اجرا کن؛ چند نمونهٔ هم‌زمان بدون ذخیره‌سازی مشترک، وضعیت بازی را با هم هماهنگ نمی‌کنند.

## فایل‌های مهم
- `server.mjs`: وب‌سرور و WebSocket
- `worker.js` و `worker-multi.js`: منطق اتاق‌ها و بازی
- `index.html` و `vs.html`: رابط بازی
- `cards/`: تصاویر کارت‌ها
- `tests/`: آزمایش دودویی سرور و اتصال WebSocket

آزمایش خودکار بررسی می‌کند که سرور بالا بیاید، صفحهٔ اصلی ارائه شود و اتصال WebSocket پیام اولیه بگیرد. این آزمایش به‌تنهایی جایگزین آزمایش کامل دو بازیکن در مرورگر نیست.

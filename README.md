# مرغ‌دونی آنلاین — نسخه Node.js

این شاخه نسخه Node.js پروژه است و رابط اصلی بازی، تصاویر کارت‌ها و منطق چندنفرهٔ موجود را نگه می‌دارد؛ این پروژه یک نمونهٔ جداگانه یا بازی بازنویسی‌شده نیست.

## اجرای محلی
1. Node.js نسخهٔ 20 یا بالاتر نصب باشد.
2. در پوشهٔ پروژه اجرا کنید: `npm install`
3. اجرا کنید: `npm start`
4. مرورگر را روی `http://localhost:3000` باز کنید.

## استقرار ابری
شاخهٔ `nodejs`، دستور نصب `npm install` و دستور اجرا `npm start` را انتخاب کنید. برنامه از پورت محیطی `PORT` استفاده می‌کند. برای نگه‌داشتن پروفایل‌ها و داده‌ها پس از راه‌اندازی مجدد، فضای دیسک پایدار برای پوشهٔ `.data` لازم است؛ در میزبانی با دیسک موقت، داده‌های ذخیره‌شده ممکن است از بین بروند.

## بررسی سلامت
مسیر `/healthz` باید پاسخ `ok` بدهد.

## فایل‌های اصلی
- `server.mjs`: وب‌سرور Node.js، سرو فایل‌ها و اتصال WebSocket
- `worker.js` و `worker-multi.js`: منطق بازی آنلاین، اتاق‌ها، لابی، درخواست بازی و کارت‌ها
- `index.html` و `vs.html`: رابط بازی
- `cards/`: تصاویر کارت‌ها

قبل از استفادهٔ عمومی، بازی دو نفره، درخواست بازی، بازی سریع، چت و استقرار روی سرویس مقصد باید عملی آزمایش شوند.

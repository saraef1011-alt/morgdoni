# مرغ‌دونی — نسخه Node.js

این برنچ بر اساس نسخه Cloudflare فرستاده‌شده ساخته شده است؛ فایل‌های بازی و کارت‌ها حفظ شده‌اند. اجرای سرور با Node.js و WebSocket انجام می‌شود و داده‌ها در data.json ذخیره می‌شوند.

## اجرا
1. Node.js نسخه 20 یا جدیدتر نصب کن.
2. در پوشه پروژه CMD باز کن و اجرا کن:
   `npm install`
   `npm start`
3. مرورگر: http://localhost:3000

میزبانی ابری باید WebSocket را پشتیبانی کند و متغیر PORT را بپذیرد.
